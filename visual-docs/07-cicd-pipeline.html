What Happens on Failure?

❌ Lint Fails

Tests never run — saves 3 minutes of CI time. Fix the lint error, push again. ruff format app/ auto-fixes most issues.

❌ Test Fails

Docker build never runs. The failing test name + traceback appear in the job log. Fix the test, push again.

🔀 PR vs Push

PRs run lint + test only (fast feedback). Push to main runs all 3 stages including Docker build. This saves build minutes on feature branches.
