🔑 Login → Dashboard Flow

1
User clicks "Sign In"
LoginPage.tsx calls useAuthStore.login(email, password)
await login(email, password);
2
Zustand → Auth Service
Zustand store calls authService.login() which calls the axios API client
api.post<AuthTokens>("/auth/login", data)
3
Nginx Rate Check
Login rate limit: 5 req/min per IP (anti-brute-force). PASS → proxy to :8000
limit_req zone=login_limit burst=3 nodelay;
4
FastAPI Auth Router
POST /api/v1/auth/login → AuthService.authenticate()
user = await auth_service.authenticate(email, password)
5
bcrypt Verify
Hash the attempt, compare with stored hash. Takes ~250ms intentionally (anti-brute-force).
verify_password(plain_password, user.password_hash) → True ✅
6
JWT Creation
Create access token (30 min) + refresh token (7 days). Payload: {sub: user_id, type: "access", exp: ...}
access = create_access_token(user.id) → "eyJhbGciOi..."
7
Tokens Stored
Frontend saves tokens to localStorage. Zustand sets isAuthenticated = true.
localStorage.setItem("access_token", tokens.access_token)
8
Navigate to Dashboard
React Router navigates to /. useDashboard() fires GET /analytics/dashboard with JWT attached by axios interceptor.
navigate("/") → DashboardPage → useDashboard()

✅ Daily Check-In Flow

1
User fills values for 6 habits
💧 Water: 8 glasses · 🏃 Exercise: ✅ Done · 😊 Mood: 7/10 · ...
updateValue(habitId, "numeric", 8)
2
Click "Save All"
DailyCheckIn builds BulkLogCreate with entries array, calls mutateAsync
bulkCreate.mutateAsync({ log_date: "2026-09-26", entries: [...] })
3
Axios POST /logs/bulk
Request interceptor attaches JWT. Vite proxy forwards to FastAPI.
POST /api/v1/logs/bulk → Authorization: Bearer eyJ...
4
LogService validates & inserts
Check: no future dates, habit belongs to user, correct value type. Then 6× INSERT INTO habit_logs.
6× INSERT INTO habit_logs (user_id, habit_id, log_date, value_numeric, ...)
5
SQS Streak Messages
For each logged habit, send an SQS message to trigger Lambda streak check (async, non-blocking).
sqs.send_message(QueueUrl=streak_queue, MessageBody={habit_id, user_id})
6
TanStack Cache Invalidation
onSuccess invalidates LOGS_KEY + ANALYTICS_KEY. Dashboard data refetches in background.
queryClient.invalidateQueries({ queryKey: ["logs"] })
7
UI Updates
Green borders + ✅ checkmarks appear. Button shows "Saved!" for 2 seconds. No page reload.
setSaved(true) → setTimeout(() => setSaved(false), 2000)

🤖 AI Chat — ReAct Agent Flow

1
User: "How's my sleep this week?"
ChatInput clears, user message appears immediately (optimistic UI). Loading spinner shows.
setMessages(prev => [...prev, userMsg]) → setIsLoading(true)
2
POST /ai/chat → AiService
Router calls AiService.chat() → creates HealthCoachAgent with 5 tools + memory
agent = HealthCoachAgent(llm, tools=[query_logs, get_analytics, ...], memory)
3
🧠 THINK: "I should check sleep data"
LLM receives system prompt + tools + conversation history. Returns a tool_call.
LLM → tool_call: query_logs(habit_name="Sleep", days=7)
4
🔧 ACT: Execute query_logs tool
Agent calls the tool. SQL: SELECT value_numeric FROM habit_logs JOIN habits WHERE name='Sleep' AND log_date >= now()-7 days
→ "Mon: 7h, Tue: 6.5h, Wed: 7.5h, Thu: 8h, Fri: 6h, Sat: 7.2h"
5
👁️ OBSERVE: LLM sees the data
Tool result added to messages. LLM decides: enough data to answer (no more tool calls).
messages.append({role: "tool", content: "[Tool: query_logs] Mon: 7h..."})
6
💬 ANSWER: LLM generates response
LLM uses the data to write a personalized, friendly answer. 2 LLM calls total, ~1500 tokens.
"Your sleep averaged 7.0h this week — up from 6.5h last week! 🎉"
7
Response appears in chat
Assistant message added to state. ChatWindow auto-scrolls to bottom. Loading spinner hides.
setMessages(prev => [...prev, assistantMsg]) → scrollIntoView()

☁️ Lambda — Streak Milestone Flow

1
User logs a habit (from check-in)
FastAPI sends SQS message after successful log creation. API returns 201 immediately — no waiting.
sqs.send_message(body={"user_id": "uuid-001", "habit_id": "water-uuid"})
2
SQS delivers to Lambda 4
AWS triggers StreakMilestoneFunction. Cold start ~500ms, warm start ~50ms.
lambda_handler(event={"Records": [{"body": "..."}]}, context)
3
Gaps-and-Islands SQL
Calculate current streak for this habit. Same algorithm as backend analytics — sync psycopg2 version.
WITH numbered AS (...) SELECT COUNT(*) as streak_length → 30 days
4
Milestone Check
30 ∈ MILESTONES [7, 14, 21, 30, 60, 90, 100, 180, 365]? → YES! Check idempotency: not already sent.
if current_streak in MILESTONES and not already_sent: → celebrate!
5
Record + Email
INSERT milestone into ai_insights. Send celebration email via SES.
send_email(subject="🔥 30-Day Streak on Water Intake!")
6
User receives email
~5-10 seconds after logging. Completely async — user never waited. Total Lambda cost: $0.000001.
📧 "🔥 30-Day Streak! Incredible work, Shreya!"

Design Patterns Used

🔄 Strategy Pattern

Used 3 times: LLM providers (Ollama/Groq/OpenAI), Email providers (Console/Resend/SES), Storage (MinIO/S3). Swap implementation via one env var — zero code changes.

3 Applications

🏭 Factory Pattern

get_llm_client() reads config, returns the correct provider. get_email_provider() does the same. One function call, correct implementation.

2 Factories

🗄️ Repository Pattern

BaseRepository<T> provides CRUD. Module repos (HabitRepository, LogRepository) extend with custom queries. Business logic never writes SQL directly.

5 Repositories

🔁 ReAct Agent Loop

Think → Act → Observe → Repeat. Max 5 iterations. LLM decides which of 5 tools to call, agent executes, feeds result back. Built from scratch — no LangChain.

From Scratch

🔗 Pipeline Pattern

Weekly report: DataCollector → Analyzer → ReportWriter. RAG: Extract → Chunk → Embed → Store. Each step produces input for the next.

2 Pipelines

💉 Dependency Injection

FastAPI Depends() provides sessions, auth, services. Tests swap real DB with test DB via dependency_overrides. Same code, different wiring.
