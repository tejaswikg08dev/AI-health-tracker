pgvector — Vector Similarity Search in PostgreSQL

The document_chunks table has a vector(768) column storing embedding vectors. Cosine similarity search: ORDER BY embedding <=> query_vector LIMIT 5. IVFFlat index makes it O(√n) instead of O(n). No separate vector database (Pinecone/Weaviate) needed — it all lives in PostgreSQL.
