3Axios Request Interceptor
Frontend
Reads JWT from localStorage, attaches to Authorization header automatically.
config.headers.Authorization = `Bearer ${token}`;
// Every request gets this — you never write it manually
⏱ +1ms — header injection
4Vite Dev Proxy
Proxy
In dev: :3000/api/* → :8000/api/* (avoids CORS). In production: Nginx does this.
// vite.config.ts
proxy: { "/api": { target: "http://localhost:8000" } }
⏱ +2ms — proxy forward
5Nginx Rate Limit Check
Nginx
General API limit: 30 req/s per IP. Client is under limit → PASS. Adds proxy headers.
limit_req zone=api_limit burst=20 nodelay; → PASS ✅
proxy_set_header X-Real-IP $remote_addr;
proxy_pass http://backend;
⏱ +3ms — rate check + proxy
6LoggingMiddleware
Middleware
Generates unique request_id, starts timer. Will log method, path, status, duration on response.
request_id = uuid4().hex[:8]
start_time = time.perf_counter()
// → passes request to next middleware
⏱ +4ms — ID + timer start
7RateLimiterMiddleware
Middleware
Redis sliding window check: INCR key, check count vs limit. /logs = general tier (60/min).
await redis.incr("rate:192.168.1.1:/api/v1/logs")
// count=5, limit=60 → PASS ✅
⏱ +5ms — Redis round-trip ~1ms
8FastAPI Router — logs/router.py
Router
URL match: POST /api/v1/logs/bulk → bulk_create_logs(). Dependency injection resolves parameters.
@router.post("/bulk", status_code=201)
async def bulk_create_logs(
data: BulkLogCreate,
user_id: UUID = Depends(get_current_user_id),
service: LogService = Depends(get_log_service),
):
⏱ +8ms — URL routing + DI resolution
9JWT Decode — get_current_user_id
Auth
Extract token from header → decode with SECRET_KEY → verify not expired → verify type="access" → return user_id.
token = request.headers["Authorization"].split(" ")[1]
payload = decode_token(token, expected_type="access")
user_id = payload["sub"] // → "uuid-shreya-001"
⏱ +10ms — JWT decode ~2ms
10Pydantic Validation — BulkLogCreate
Validation
Request body parsed and validated: log_date must be ≤ today, entries array must be non-empty, each entry needs matching value type.
class BulkLogCreate(BaseModel):
log_date: date # validated: not future
entries: list[BulkLogEntry] # min_length=1
⏱ +12ms — schema validation
11LogService.bulk_create_logs()
Service
Business logic: verify each habit_id belongs to user, check value matches habit_type (numeric gets value_numeric, etc.), loop and create.
for entry in data.entries:
habit = await habit_repo.get_user_habit(user_id, entry.habit_id)
// Validate ownership + type match
log = await log_repo.create(HabitLog(...))
⏱ +20ms — validation + object creation
12LogRepository → SQLAlchemy → PostgreSQL
Database
6× session.add(HabitLog) → session.commit() → PostgreSQL executes 6 INSERT statements in one transaction.
-- Generated SQL (6 times):
INSERT INTO habit_logs
(id, user_id, habit_id, log_date, value_numeric, created_at)
VALUES ('uuid', 'uuid-shreya', 'uuid-water', '2026-09-26', 8.0, now());
⏱ +80ms — 6 inserts + commit (~10ms each)
13SQS — Streak Check Messages (async)
Event
For each logged habit, send a message to the streak SQS queue. Non-blocking — API doesn't wait for Lambda to process.
sqs.send_message(
QueueUrl=streak_queue,
MessageBody=json.dumps({"user_id": "...", "habit_id": "..."})
) // fire and forget
⏱ +85ms — SQS send ~5ms (async)
14201 Created → JSON Response
Response
FastAPI serializes 6 HabitLog objects → JSON array. Gzip compressed by Nginx (1.2KB → 400 bytes). Logging middleware logs: POST /logs/bulk 201 285ms.
[
{ "id": "uuid", "habit_id": "water-uuid", "value_numeric": 8.0, ... },
{ "id": "uuid", "habit_id": "exercise-uuid", "value_boolean": true, ... },
// ... 4 more
]
⏱ +285ms — total backend time
15TanStack Cache Invalidation + UI Update
Frontend
onSuccess: invalidate logs cache + analytics cache. Green checkmarks appear. "Saved!" shows for 2 seconds. Dashboard data refreshes in background.
queryClient.invalidateQueries({ queryKey: ["logs"] });
queryClient.invalidateQueries({ queryKey: ["analytics"] });
setSaved(true); // ✅ green checkmarks appear
⏱ +300ms — total round-trip. User sees ✅

What Just Happened

In 300 milliseconds, the request passed through 15 layers: React component → TanStack mutation → Axios interceptor → Vite proxy → Nginx rate limiter → 2 middleware layers → FastAPI router → JWT auth → Pydantic validation → Service logic → Repository → PostgreSQL (6 INSERTs) → SQS event → JSON response → UI update. The user only saw: click → green checkmarks.
