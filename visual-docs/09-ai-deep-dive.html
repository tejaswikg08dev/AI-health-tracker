LLM Strategy Pattern — Swap Provider via Config

One abstract interface, three implementations. Change LLM_PROVIDER in .env — zero code changes. Click a provider:

🦙
Ollama
Local, 100% free, offline-capable. Runs llama3.1:8b on your machine.
Development
⚡
Groq
Cloud, free tier (14.4K req/day). Fastest inference — ~50ms latency.
Staging
🧠
OpenAI
GPT-4o, best quality. Pay per token. Production-grade reliability.
Production

How It Works

# config.py
LLM_PROVIDER="ollama" # ← change this one line

# factory.py
def get_llm_client() -> BaseLLMClient:
  if provider == "ollama": return OllamaClient()
  if provider == "groq": return GroqClient()
  if provider == "openai": return OpenAIClient()

# All 3 implement: chat(), stream_chat(), embed()
# The rest of the app calls llm.chat() — doesn't know which provider

ReAct Agent — Think → Act → Observe

The agent receives a question, reasons about what data it needs, calls tools to fetch data, observes results, and generates a personalized answer. Max 5 iterations.

🔍 query_logs 📊 get_analytics 🔗 correlate 📄 search_docs 📝 create_plan

Example: "Why am I tired this week?"

💭
THINK #1
"I should check sleep data for this week"
🔧
ACT #1 → query_logs
query_logs(habit_name="Sleep", days=7)
👁️
OBSERVE
"Mon: 5h, Tue: 4.5h, Wed: 6h, Thu: 5h, Fri: 4h, Sat: 5.5h — avg: 5.0h"
💭
THINK #2
"Sleep is very low (5h vs target 7.5h). Let me check if exercise correlates."
🔧
ACT #2 → correlate
correlate(habit_a="Sleep", habit_b="Exercise")
👁️
OBSERVE
"Correlation: 0.78 (strong positive). On days you exercise, you sleep 1.5h more."
💭
THINK #3
"I have enough data. Low sleep + strong exercise correlation = clear answer."
💬
FINAL ANSWER
"You're averaging only 5 hours of sleep this week — well below your 7.5h target. I found a strong correlation (0.78) between exercise and sleep: on days you work out, you sleep ~1.5 hours more. You only exercised twice this week. Try adding 3 more exercise sessions and you'll likely see your sleep improve significantly. 💪"
2 tool calls · 3 think steps · ~1500 tokens · ~3 seconds
