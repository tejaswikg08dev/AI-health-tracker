Deploy Steps

1
Build & Push Docker Image
Build the production stage of the Dockerfile (150MB), tag with git SHA, push to ECR.
docker build -t health-tracker-backend ./backend
docker tag ... <account-id>.dkr.ecr.us-east-1.amazonaws.com/health-tracker:latest
docker push ...
2
Update ECS Task Definition
Point the task definition to the new image tag. Secrets come from AWS Systems Manager Parameter Store (not env vars).
aws ecs register-task-definition --family health-tracker-backend --container-definitions '[{"image":"...latest",...}]'
3
Rolling Update (Zero Downtime)
ECS starts new tasks → health check passes → old tasks drain connections → old tasks stop. Users never see downtime.
aws ecs update-service --cluster health-tracker --service backend --task-definition health-tracker-backend:latest
4
Deploy Frontend to S3 + CloudFront
Build React app with production API URL, upload to S3, invalidate CloudFront cache.
VITE_API_URL=https://api.healthtracker.app npm run build
aws s3 sync dist/ s3://health-tracker-frontend --delete
aws cloudfront create-invalidation --distribution-id <id> --paths "/*"
5
Deploy Lambda Functions
SAM packages all 6 functions + shared/, creates/updates CloudFormation stack with SQS queues, S3 bucket, EventBridge rules.
cd lambda_functions
sam build && sam deploy
6
Run Migrations
ECS exec into a running container, run Alembic migrations against the production RDS database.
aws ecs execute-command --cluster health-tracker --task <task-id> --command "alembic upgrade head"
